# Habit

Habit 是一个以本地数据为主的 Android 日常生活工作台，包含习惯打卡、饮食记录和可选的 AI 洞察。

## 0.6.0

- AI 功能默认关闭；不配置模型时，原有习惯、饮食、统计和备份功能照常使用。
- “AI 洞察”新增模型档案与功能绑定：可分别为综合周报和图片热量估算选择已启用、能力匹配且测试通过的 OpenAI 兼容模型。
- 综合周报只在用户确认后请求模型，仅发送生成周报所需的结构化习惯与饮食数据，不发送照片、API Key 或其他本地文件；生成结果可预览、保存、替换和查看历史。
- 图片热量估算只用于含照片的餐食。只有用户明确选择照片并点击估算、再次确认后，所选照片才会发送；估算值可在采用前调整。
- API Key 使用 Android Keystore 保护，不进入 Room；API Key 不会写入备份。恢复备份或换机后需要重新输入 Key，并重新测试、绑定对应功能。
- 饮食详情页进一步细化摘要、餐食/饮品属性、备注、照片和 AI 热量依据，便于回看估算范围、采用值与模型快照。
- Room 升级到 v5，通过 `MIGRATION_4_5` 保留 0.5.1 的习惯、饮食和照片数据；备份升级为 schema 5，并继续读取 schema 1–4。
- 新增 `INTERNET` 权限，仅供用户主动配置并调用 AI 服务；普通本地功能不会自行发起 AI 请求。

## 隐私边界

Habit 不提供账号、云同步或后台 AI。模型配置和功能绑定保存在本机，API Key 单独加密保存；应用备份会包含非秘密的模型配置、绑定、周报及热量估算依据，但不会包含 API Key。HTTP 端点必须由用户明确确认风险，日常使用建议选择 HTTPS。

## 0.4.1

- 全部页面统一顶部安全区，习惯详情与分类管理不再遮挡状态栏。
- 侧栏入口与子页面返回来源分离，切换模块会清理旧页面栈。
- 返回与月历翻页箭头改为大号、无圆形底的轻量样式。

## 0.4.0

- 饮食记录支持相册和相机照片，每条最多 3 张，文件保存在应用私有目录。
- 支持“再记一次”，复制点单属性并使用当前北京时间，不复制原记录照片。
- 支持饮食模板：正餐/加餐与饮品分组折叠、重命名、排序、删除及工作台快捷记录。
- 数据库升级到 Room v3，保留 0.3.2 的本地习惯与饮食数据。
- 新备份为 `.habitbackup.zip`，包含 `backup.json`、模板和照片；仍可导入 v1/v2 `.habitbackup.json`。
- 合并导入发生冲突时以更新时间较新的数据为准；损坏或缺失照片会跳过并提示，不影响文字数据。

备份默认位置：`内部存储 / Download / Habit / 数据备份`。
