# Habit

Habit 是一个面向日常生活的 Android 工作台，目前包含习惯打卡与饮食记录两组可折叠模块。

## 0.4.0

- 饮食记录支持相册和相机照片，每条最多 3 张，文件保存在应用私有目录。
- 支持“再记一次”，复制点单属性并使用当前北京时间，不复制原记录照片。
- 支持饮食模板：正餐/加餐与饮品分组折叠、重命名、排序、删除及工作台快捷记录。
- 数据库升级到 Room v3，保留 0.3.2 的本地习惯与饮食数据。
- 新备份为 `.habitbackup.zip`，包含 `backup.json`、模板和照片；仍可导入 v1/v2 `.habitbackup.json`。
- 合并导入发生冲突时以更新时间较新的数据为准；损坏或缺失照片会跳过并提示，不影响文字数据。

备份默认位置：`内部存储 / Download / Habit / 数据备份`。
