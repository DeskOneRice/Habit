# Habit 顶部栏、导航来源与月历控件统一设计

## 目标

修复页面顶部区域与系统状态栏重叠、侧栏跳转恢复旧子页面，以及导航和月历按钮视觉不统一的问题。

## 设计

### 统一顶部区域

- 所有带标题的业务页面使用公共 `HabitTopAppBar`，由 Material 3 顶部栏统一处理状态栏安全区。
- 习惯详情页和分类管理页不再在滚动内容中手工绘制标题栏。
- 页面正文只应用一次顶部栏提供的内容边距，避免重复留白或标题随正文滚动。

### 区分菜单与返回来源

- 模块根页面显示侧栏菜单按钮 `☰`。
- 编辑页、详情页，以及从模块内部进入的分类管理页显示返回箭头。
- 分类管理保留两个明确入口：侧栏入口作为模块根页面；习惯列表或设置入口作为子页面。两者复用同一内容组件，但导航模式不同。
- 点击任一侧栏入口时关闭侧栏，并清理此前模块和子页面栈；目标页面重新显示其根状态，不恢复先前打开的详情或编辑页面。

### 轻量导航控件

- 顶部返回按钮和月历上一月、下一月按钮全部取消实心或圆形底色。
- 控件仍保留至少 48dp 的触控区域，箭头字号增大，以兼顾可见性和易点击性。
- 菜单按钮与返回按钮保持不同符号和无障碍说明，避免来源混淆。

## 验证

- 自动测试覆盖侧栏目的地、分类页两种导航来源，以及侧栏跳转不恢复旧栈的策略。
- UI 测试确认公共顶部栏的菜单/返回语义和轻量按钮标签。
- 构建并运行现有单元测试、界面测试与静态检查；生成新的兼容升级 APK。

## 兼容性

本次只修改界面与导航，不修改 Room 数据结构、备份格式或用户数据，因此旧版本本地数据可直接保留。
