# Habit 饮食与导航 UI 修复规格

## 目标

修复 0.3.0 饮食模块与导航中的六项可见问题，不改变数据库结构、备份格式或已有饮食记录内容。

## 已确认行为

1. 侧边栏的工作台、分组、子页面和设置入口全部使用 Emoji，不再混用几何符号与 Emoji；展开/收起提示保持统一的文字箭头。
2. 新建及编辑习惯页面使用贴近页面左侧的标准返回箭头，同时保留至少 48dp 的触控范围。
3. 饮食日记顶部周视图固定为七等分；星期和日期分两行显示，每列水平、垂直对齐。
4. 记一餐页面的日期和时间分别可点击选择。日期选择器允许直接跨月、跨年；时间选择器允许精确选择小时和分钟。
5. 新建记录时允许选择“正餐/加餐”或“饮品”；编辑已有记录时类型锁定，只显示当前类型，不显示另一个类型入口。
6. 饮食日记空状态的两行提示在可用宽度内水平居中。

## 实现边界

- 复用现有 Compose Material 3 组件，不引入新依赖。
- 时间保存仍使用现有 `DietEditorViewModel`、设备时区和 `occurredAt` 数据流。
- 不修改 Room schema 版本，不触发数据迁移。
- 对时间更新与记录类型锁定增加回归测试；纯布局问题通过编译与模拟器预览确认。

## 验收

- 新建习惯页返回箭头视觉上靠左且可点击返回。
- 周视图七列等宽，所有星期与日期数字中心线一致。
- 可选择任意日期以及 00:00–23:59 的时间。
- 编辑正餐记录只显示正餐类型，编辑饮品记录只显示饮品类型。
- 空状态两行文字居中。
- 侧边栏入口全部为 Emoji 风格。
