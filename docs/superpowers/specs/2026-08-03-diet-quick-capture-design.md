# Habit 0.4.0 饮食快速记录设计

## 目标

在保持纯本地、可完整迁移和北京时间语义的前提下，通过餐食照片、快速复记和常用模板显著缩短饮食记录时间。

## 功能范围

### 餐食照片

- 每条饮食记录最多关联 3 张照片。
- 支持从系统相机拍摄和从系统相册选择。
- 选择后立即复制到应用私有目录，不长期依赖外部相册 URI。
- 编辑页显示缩略图，可预览大图、移除以及继续添加。
- 删除饮食记录时删除其不再被引用的照片文件。
- 照片不写回系统相册、不上传网络。

### 快速复记

- 饮食日记的每条记录提供“再记一次”。
- 复记复制记录类型、餐次、描述、食物明细、最终热量、饮品属性、加料和备注。
- 复记不复制原记录 ID、创建/更新时间和原照片。
- 新记录日期和时间使用点击时的北京时间，保存前仍可编辑。

### 常用模板

- 编辑记录时可将当前内容保存为模板。
- 模板分为“餐食”和“饮品”两个可折叠分组。
- 模板支持命名、排序和删除；名称必填，同组内允许重名。
- “保存为模板”弹窗提供“包含照片”开关，默认关闭；开启时复制当前记录照片作为模板照片。
- 从模板创建时复制内容字段和可选模板照片，日期时间使用当前北京时间。
- 模板照片独立复制，删除原记录不影响模板。
- 工作台“今日饮食”卡提供“模板记录”快捷入口。

## 界面结构

- 饮食编辑页在记录类型和发生时间之后增加照片区，显示 3 格缩略图槽位。
- 饮食日记记录卡保留“查看”，增加低强调度的“再记一次”。
- 侧边栏饮食组新增“常用模板”入口，继续使用 Emoji 图标。
- 模板页顶部提供餐食/饮品分组，默认展开；每个模板卡显示名称、摘要、热量和可选封面图。
- 从日记或模板进入编辑页时，标题分别显示“再记一次”或“从模板记录”。

## 数据模型

Room 数据库从 v2 升级到 v3：

- `diet_photos`：`id`、`mealRecordId?`、`templateId?`、`relativePath`、`sortOrder`、`createdAt`。
- `diet_templates`：模板基础字段、记录类型、餐次、描述、热量、饮品属性、排序和时间戳。
- `diet_template_food_items`：模板食物明细。
- `diet_template_toppings`：模板饮品加料。
- 照片必须且只能属于一条饮食记录或一个模板。

迁移 `MIGRATION_2_3` 只创建新表和索引，不修改现有记录，因此旧版本地数据原样保留。

## 照片文件管理

- 私有目录：`filesDir/diet_photos/`。
- 文件名使用随机 UUID 和受支持扩展名，禁止使用用户原始文件名作为路径。
- 导入流先写临时文件，成功解码且大小受限后原子移动到正式目录。
- 单张图片最大 12 MB；超过限制时拒绝并提示。
- 数据库事务成功但文件操作失败时回滚新文件；删除采用“先提交数据库，再清理孤儿文件”的可重试策略。

## v3 备份格式

- 新备份扩展名：`.habitbackup.zip`。
- 压缩包根目录必须包含 `backup.json`，照片位于 `photos/<relativePath>`。
- `backup.json` schemaVersion 为 3，并包含照片和模板元数据。
- 导出只打包数据库仍在引用的照片。
- 导入前校验 ZIP 路径，拒绝绝对路径和 `..`，防止目录穿越。
- 导入继续支持 v1/v2 `.habitbackup.json`；这些旧备份没有照片和模板，按空集合处理。
- 合并导入继续以更新时间较新的结构化数据为准；照片以内容文件和新 ID 导入，避免覆盖现有文件。
- 某张照片损坏或缺失时跳过该照片、保留文字记录，并在结果中报告跳过数量。
- 完全替换导入成功后清理数据库不再引用的孤儿照片；导入失败时保留原数据库和照片。

## 时间与签名

- 所有新记录、模板和备份文件名继续使用 `Asia/Shanghai` 业务时区。
- 数据库时间戳继续保存 epoch milliseconds。
- 0.4.0 使用已固定证书，指纹保持 `8674967e7901174339cd4fc85726ebce59b572a7ab58a799139e300a69382abb`。

## 错误处理

- 相机取消或相册未选择不创建照片记录。
- 图片复制失败只提示该图片失败，不丢失正在编辑的文字内容。
- 模板保存失败保留编辑页状态。
- 快速复记创建的是可编辑草稿，用户取消时不写入数据库或照片。
- 备份空间不足、压缩包损坏和照片跳过数量均使用明确中文提示。

## 测试与验收

- Room v2 数据库迁移到 v3 后原习惯、打卡和饮食记录数量不变。
- 每条记录最多 3 张照片，删除记录后无孤儿文件。
- 复记完整复制内容但使用当前北京时间，且不复制原照片。
- 模板创建、排序、删除及从模板生成草稿均通过仓库测试。
- v3 备份导出后包含 JSON 和所有引用照片，并可恢复到空数据库。
- v1/v2 JSON 备份仍可导入。
- 恶意 ZIP 路径被拒绝；缺失单张照片时文字数据仍恢复。
- 完整单元测试、Room 仪器测试和 APK 构建通过。
