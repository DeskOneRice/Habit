# Habit 0.5.1 饮食阅读与 UI 一致性实施计划

> 依据：`docs/superpowers/specs/2026-08-10-diet-diary-reading-polish-design.md`

目标是把已批准的饮食阅读、温度兼容、照片预览、统计可视化和全局 UI 统一内容实现为可覆盖安装的 0.5.1 APK，并保持旧数据库及备份兼容。

## 任务 1：建立共享显示和温度规则

- 在领域层新增饮食显示纯函数，覆盖记录类型、餐次、饮品枚举、记录名称、记录类型行和统一温度文本。
- 先扩充 `DietStatisticsTest` 与新增显示规则测试，验证中文映射、旧温度合并和空值兜底。
- 修改编辑、详情、模板、日记和统计，删除重复映射与直接 `.name` 展示。
- 新保存饮品只写 `temperature`，清空 `iceLevel`，数据库结构不变。

## 任务 2：完成饮食日记阅读体验

- 先补 `DietDiaryViewModelTest`，覆盖日期降序、组内时间及 ID 降序、名称与类型。
- 实现最近记录/按日查看双页签和横向手势切换。
- 调整记录卡右侧垂直居中、名称/类型/辅助信息顺序。
- 实现共享照片预览层，并接入列表、详情和编辑页；缺失或损坏图片保持 Emoji 回退。

## 任务 3：实现 7/30 天饮食统计

- 扩充统计模型：餐食记录数、饮品记录数、每日趋势、统一温度排行。
- 先补统计纯函数和 ViewModel 周期切换测试，覆盖空数据、单类型和计数恒等式。
- 实现四项概览、周期切换、趋势图、构成环图和水平排行条。
- 所有饮品分类显示中文，所有统计文案使用“温度”。

## 任务 4：统一日历与全局入口

- 为日历标识两位置规则和月度概览补纯函数或 UI 测试。
- 收紧同日标识布局，重做“本月概览”三指标卡，保持轻量月份箭头。
- 抽取共享纯 `+` FAB，替换我的习惯和饮食日记的不同实现。
- 删除我的习惯顶部冗余操作，统一“日历”术语。

## 任务 5：整理分类与设置

- 更新分类 UI 测试：顶部无 `+`、三入口等宽居中、新建入口位于当前列表末尾且唯一。
- 调整分类管理布局，同时保持现有增删改和预设分类保护逻辑。
- 从设置页及导航参数中删除重复分类入口，保留侧边栏和编辑页入口。
- 更新依赖该函数签名的 UI 测试。

## 任务 6：版本、回归与交付

- 将版本更新为 `versionCode 11`、`versionName 0.5.1`，继续使用稳定签名。
- 依次运行 JVM 单元测试、Android 测试编译、Lint、Debug 和 Release 构建。
- 使用连接设备或模拟器验证覆盖安装、启动、主要页面和旧数据保留。
- 输出带版本号的 Release APK，记录 SHA-256、文件大小与绝对路径。

## 完成证据

- 测试输出覆盖规格第 9、11、16 节。
- 代码扫描不再发现用户界面直接显示内部枚举值、旧“冰量”输入、旧“打开月历”和“正餐 / 加餐”。
- Release APK 能用 Android 工具确认包名、版本和签名，并可覆盖安装到现有 `com.habit.app`。
